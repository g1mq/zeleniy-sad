ER-диаграмма информационной системы

Для сдачи: Ctrl+P → «Сохранить как PDF». Включите все таблицы, связи, PK и FK.

roles

  • PK id INT
  • role_name VARCHAR(20) UNIQUE

users

  • PK id INT
  • login VARCHAR(50) UNIQUE
  • password_hash VARCHAR(255)
  • FK role_id → roles.id
  • full_name, phone, created_at

growing_conditions

  • PK id INT
  • climate_zone, soil_type
  • sunlight, watering

products

  • PK id INT
  • article UNIQUE, name, type ENUM
  • brand, price, quantity
  • category, description, image_path
  • planting_season, created_at

product_condition_link

  • PK product_id
  • PK condition_id
  • FK → products, growing_conditions
  • N:M связь

orders

  • PK id INT
  • FK user_id → users.id
  • order_date, status ENUM
  • total_amount, delivery_address
  • phone, created_at

order_items

  • PK id INT
  • FK order_id → orders.id
  • FK product_id → products.id
  • count, price_at_order
Связи:
roles (1) — (N) users  |  users (1) — (N) orders  |  orders (1) — (N) order_items  |  products (1) — (N) order_items  |  products (N) — (M) growing_conditions через product_condition_link
