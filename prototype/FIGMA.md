# Чеклист прототипа для Figma (Блок 1)

## 6 обязательных экранов
1. `login.html` — Вход
2. `register.html` — Регистрация + CAPTCHA
3. `catalog.html` — Каталог
4. `product-form.html` — Форма товара (CRUD)
5. `orders.html` — Список заказов
6. `order-detail.html` — Детали заказа (CRUD)

## 5+ логических переходов (Prototype → Interactions)
- Вход → Каталог (кнопка «Войти»)
- Вход → Регистрация
- Вход → Каталог как Гость
- Каталог → Форма товара
- Меню → Заказы
- Заказы → Детали заказа

## Компоненты
- **Кнопки:** Default, Hover, Pressed, Disabled (см. низ `login.html`)
- **Поля:** Empty, Focused, Error (см. `register.html`)
- **Карточка товара** с иконками 🌱 💧 ☀️

## Брендинг
- Логотип на каждом экране — файл `images/logo.png` (уже в прототипе)
- Цвета: #22C55E, #8B7355, #FCD34D, фон #F8FAF5
- Шрифты: Nunito (заголовки), Open Sans (текст)

## CAPTCHA
Отдельный блок на экране регистрации с визуализацией примера «7 + 3 = ?».

HTML-прототип можно использовать как референс при верстке фреймов в Figma.
